# Баланс и расходы (₽) для DeepSeek Harness

Неофициальный русский форк плагина
[`@pipilu123566/dsh-balance`](https://github.com/pipilu123566/deepseek-harness-plugin).
Показывает балансы провайдеров и расходы за день в боковой панели DSH, а все суммы
дополнительно пересчитывает в рубли по курсу ЦБ РФ.

- Репозиторий: <https://github.com/artuasova/dsh-balance-ru>
- Готовый архив: [`dsh-balance-ru-1.2.0.tgz`](../../releases/download/v1.2.0/dsh-balance-ru-1.2.0.tgz)
  (все версии — на странице [Releases](../../releases))

![Иконка плагина](icon.svg)

## Что умеет

- Балансы: аккаунт DeepSeek, официальный DeepSeek API, OpenRouter, SiliconFlow и другие
  провайдеры, у которых есть документированный endpoint баланса.
- Расходы за сегодня: сумма, разбивка по моделям и по сессиям, расход за каждый ход
  в чате. Оценка строится по записанному расходу токенов и ценам моделей.
- **Рубли**: рядом с каждой суммой появляется приблизительный пересчёт
  `≈ 295 ₽` — по курсу ЦБ РФ (USD и CNY). Это только отображение: исходные суммы и
  валюты не меняются и не складываются между собой.
- Цены моделей: свои цены за вход, выход, чтение и создание кэша для пары
  «поставщик/модель»; сохранение пересчитывает исторические оценки.
- Ошибки, отсутствующие ключи, лимиты и неотправленный расход показываются явно, а не
  как нулевой баланс.
- Русский интерфейс плагина встроен: отдельный языковой пакет не нужен.

## Требования

- DeepSeek Harness **0.2.1-rc.5** (Desktop). Версия проверяется через
  `engines.dsh` в `package.json`.
- ОС: Windows, macOS или Linux — плагин клиентский, работает в Web UI DSH.
- Для рублёвого пересчёта нужен интернет (курс ЦБ, кэш 6 часов). Без сети суммы
  показываются как обычно, без строки в рублях.

## Установка

1. Полностью закройте DeepSeek Harness (не просто сверните окно).
2. Скачайте `dsh-balance-ru-1.2.0.tgz` со страницы Releases этого репозитория
   (или соберите сами: `npm install && npm pack`).
3. Если раньше стоял оригинальный `@pipilu123566/dsh-balance`, сначала удалите его —
   в профиле должен остаться только один плагин баланса:

   ```sh
   dsh plugin --profile desktop remove @pipilu123566/dsh-balance
   ```

4. Установите архив:

   ```sh
   dsh plugin --profile desktop add ./dsh-balance-ru-1.2.0.tgz --ignore-scripts
   ```

   Если `dsh` не в `PATH` (macOS):

   ```sh
   '/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh' \
     plugin --profile desktop add ./dsh-balance-ru-1.2.0.tgz --ignore-scripts
   ```

   На Windows: `"%LOCALAPPDATA%\Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd"`
   `plugin --profile desktop add .\dsh-balance-ru-1.2.0.tgz --ignore-scripts`.

5. Откройте Harness: внизу боковой панели появится кнопка **«Баланс»**. Наведите
   курсор или нажмите, чтобы закрепить панель; `Esc` закрывает.

## Русский язык

Плагин сам добавляет язык «Русский» (fallback `en`) и свой словарь. Переключение:
**Настройки → Общие → Язык → Русский**. Переводится интерфейс этого плагина; остальной
DSH останется на английском, если языковой пакет не установлен. Недостающие ключи всегда
берутся из английского словаря.

## Как считается рубль

- Источник: `https://www.cbr-xml-daily.ru/daily_json.js` (зеркало дневных курсов ЦБ РФ,
  CORS разрешён). Резервный источник: `https://open.er-api.com/v6/latest/USD`.
- Через USD считаются и рубли, и юани; кэш — 6 часов, запрос асинхронный и не блокирует
  панель.
- Значение приблизительное (`≈`), округление: до копеек при сумме меньше 100 ₽,
  до рублей от 100 ₽. Подсказка при наведении на `₽` показывает дату курса.
- Сеть/API балансов не задействованы: курс запрашивает браузер, суммы баланса и расходов
  по-прежнему приходят только от штатных сервисов DSH.

## Сборка, тесты

```sh
npm install

```

Локальная установка из папки (для разработки):

```sh
dsh plugin --profile desktop add "/полный/путь/к/dsh-balance-ru" --ignore-scripts
```

## Отличия от `@pipilu123566/dsh-balance@1.1.0`

- Добавлен пересчёт в рубли (панель, расходы за день, модели/сессии, расход за ход).
- Встроен русский словарь (86 строк) и регистрация языка `ru`.
- Переименована поставка: пакет `dsh-balance-ru`, id плагина `dsh-balance-ru`,
  id слотов `dsh-balance-ru` / `dsh-balance-ru-turn`. Внутренние имена сервисов
  (`pipiluBalance`, проекция `pipiluTokenUsage`, namespace словаря `pipilu.balance`)
  сохранены для совместимости с апстримом.
- Регистрация словарей не роняет слоты после hot reload.
- Метаданные плагина на русском, английском и китайском.
- Добавлен тест `rub.test.js`.
